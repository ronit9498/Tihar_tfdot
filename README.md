# The Five Days of Tihar

An interactive microsite that takes visitors through the five days of Nepal's Tihar festival.

**Live site:** https://ronit9498.github.io/Tihar_tfdot/

## About
Flipping a light switch brings a dark night scene to life with glowing lights, diyos and fireworks. Illustrated cards let visitors explore the traditions and significance of each day of Tihar: Kaag Tihar, Kukur Tihar, Laxmi Puja, Goru Tihar / Mha Puja and Bhai Tika.

## Features
- Interactive light switch with animated string lights, diyos, mandalas and fireworks
- Illustrated cards for each of the five days
- Keyboard-accessible tabs and switch
- Responsive layout for mobile and desktop

## Built with
HTML, CSS and vanilla JavaScript. No frameworks or libraries.

## Files
- `index.html`: page structure
- `style.css`: styling and animations
- `tabs.js`: day card illustrations (SVG)
- `script.js`: lights, fireworks and day details
